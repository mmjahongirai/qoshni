# QO'SHNI

Mobile app for neighbors — built for Uzbekistan first, then the world.

## Platforms

- iOS (App Store)
- Android (Google Play)

## Stack

- [Expo](https://expo.dev) + React Native + TypeScript

## Getting started

```bash
npm install
npm start
```

Then scan the QR code with Expo Go (Android / iOS).
